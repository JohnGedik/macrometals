# Data Rights Register

This is the operational record for public data-use permissions. It is not legal advice or a substitute for provider agreements. Permission flags may be enabled when the rights status is documented from the provider's published terms, series metadata, or written permission. A public-use grant does not imply caching, archival, API automation, or derivative-display rights.

Do not store secrets, full confidential contracts, account details, or API keys here. Store a non-sensitive evidence reference (document title, repository path or provider URL) and, for confidential agreements, the location in the approved private document store.

## Record Fields

For each permission, record:

- Record ID and provider/series identifier.
- Activity: automated retrieval, public display, derived values, caching, raw archival, or internal research.
- Evidence reference, governing terms/version, and the exact clause or grant.
- Covered product, data fields, territory, audience, commercial/non-commercial scope, and exclusions.
- Attribution text and link required in the application.
- Effective date, expiry/review date, revocation conditions, and reviewer/owner.
- Corresponding environment flag(s), if any.

## Requested Dataset Notes

### Central Bank Gold Purchases

The source is the World Gold Council's [Gold Reserves by Country](https://www.gold.org/goldhub/data/gold-reserves-by-country) page and its "Changes in World Official Gold Reserves" workbook. The dashboard sums the reported country-level monthly changes in tonnes. This is not WGC's broader estimate of total central-bank demand, which includes estimated unreported activity. Display, derived use, caching, and archival are owner-reported as approved; workbook downloads still require authenticated access.

### Gold ETF Holdings data

The source is WGC's [Gold ETFs, holdings and flows](https://www.gold.org/goldhub/data/gold-etfs-holdings-and-flows) page and its monthly Excel workbook. The dashboard uses the workbook's global month-end holdings total in tonnes. WGC lists Bloomberg, company filings, ICE Benchmark Administration, and WGC as sources; the owner reports that the applicable workbook and underlying-source rights are approved. Authenticated downloads are not yet automated.

### Gold Futures COT Positioning

The source is the CFTC's weekly [Disaggregated Futures Only report](https://publicreporting.cftc.gov/resource/72hh-3qpy.json), queried for COMEX Gold (contract `088691`). The factor is Managed Money net positions, calculated as long minus short and displayed in thousand contracts. CFTC reports positions as of Tuesday and generally releases them Friday. The CFTC FAQ says API tokens are not currently provided or required for ordinary PRE API use, provided the API is not overused. The owner reports approval for automated retrieval and public display of this derived series; the raw response is not archived, requests are uncached, and the dashboard attributes CFTC with a link to the report environment.

### Geopolitical Risk Index

The source is the [Caldara–Iacoviello GPR Index site](https://www.matteoiacoviello.com/gpr.htm), specifically the monthly Recent GPR column in its [Excel export](https://www.matteoiacoviello.com/gpr_files/data_gpr_export.xls). The adapter excludes the daily, historical, and older-methodology series, records the download date as the vintage, and refreshes the parsed series in memory hourly without archiving the workbook. The site states CC BY 4.0 and requests author/source credit and download date; recent observations are marked preliminary because the provider may revise them.

### Broad U.S. Dollar Index

The Gold macro factor uses the Federal Reserve Board's [Nominal Broad U.S. Dollar Index (DTWEXBGS)](https://fred.stlouisfed.org/series/DTWEXBGS) through FRED. This is a daily trade-weighted broad index with January 2006=100; it is not ICE's DXY/USDX basket. The owner reports FRED approval for this feed. Attribute the Board of Governors through FRED; requests are uncached and raw data are not archived.

## Recording a Permission

Copy a pending row, preserve the Record ID, fill every applicable field, and link only the non-sensitive evidence reference. Then update the corresponding server environment flag in the deployment configuration. For FRED archival, both the public-use record and the separate archival record must be complete before adding that series to `FRED_ARCHIVE_PERMITTED_SERIES`. Never set a flag based only on data availability, attribution, or repository commit authorship.
